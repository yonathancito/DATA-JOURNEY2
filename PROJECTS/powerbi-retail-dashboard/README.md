# Retail Sales Dashboard

## Objective
Analyze retail sales performance using Power BI.

## Business Questions
- Which region generates the most revenue?
- Which product dominates sales?
- How are sales evolving?

## Tools Used
- Power BI
- Power Query
- Excel

## KPIs
- Total Sales
- Average Sales
- Transaction Count

## Key Findings
- Lima leads sales performance.
- Laptops generate the highest revenue.
- Premium sales strongly impact total revenue.
