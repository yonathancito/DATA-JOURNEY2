# SQL Retail Analysis

## Objective
Analyze retail sales data using SQL.

## Business Questions
- Which region sells the most?
- Which seller performs best?
- What are the highest sales?

## Tools Used
- PostgreSQL
- SQL
- DBeaver

## Key Findings
- Laptops generated the highest revenue.
- Lima and Arequipa showed strong sales.
- High-ticket products dominate revenue.

## Skills Practiced
- SELECT
- WHERE
- ORDER BY
- LIMIT
