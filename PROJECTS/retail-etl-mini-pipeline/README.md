# Retail ETL Mini Pipeline

## Objective
Simulate a complete data analytics workflow using SQL, Python, and Power BI.

## Workflow
SQL → Extraction
Python → Transformation
Power BI → Visualization

## Tools Used
- PostgreSQL
- Python
- Power BI
- Excel

## Business Questions
- Which region generates the most revenue?
- Which sellers perform best?
- Which sales are premium?

## Skills Practiced
- SQL querying
- Data transformation
- KPI analysis
- Dashboard creation
- Storytelling

## Key Findings
- Premium sales strongly impact revenue.
- Some sellers dominate performance.
- Interactive dashboards improve analysis.
